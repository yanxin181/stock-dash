# 图表关键词与测试指令

本文适用于当前的**本地模式**。系统按固定规则识别文字，使用内置模拟数据绘制图表；大模型模式尚未接入。数据截止于 2026-01-30，并非实时行情。

## 基本输入格式

```text
分析 + 公司 + 时间范围 + 指标 + 可选的图表类型或分析要求
```

例如：`分析 A 公司最近 30 个交易日的股价和成交量。`

除了已有看板后的特定追问，每条新需求都应明确公司、一个时间范围和至少一个支持的指标或分析要求。系统会检查无法识别的剩余文字，近义词不能保证可用。

## 公司和时间

| 类别 | 支持的关键词或格式 | 说明 |
| --- | --- | --- |
| 公司 | `A公司`、`A股票`、`B公司`、`B股票` | A、B 不区分大小写，关键词内部可有空格；必须写“公司”或“股票”。 |
| 时间 | `最近N个交易日`、`最近N交易日`、`近N个交易日`、`近N交易日` | N 使用阿拉伯数字，范围为 2～60；只能指定一个时间范围。 |

例如：`A 公司最近 30 个交易日`、`b股票近10交易日`。时间范围以模拟数据截止日为准，不是当前日期。

## 指标与图表类型

| 指标关键词 | 生成内容 | 默认类型 |
| --- | --- | --- |
| `股价`、`收盘价` | 收盘价走势，单位为元 | 折线图 |
| `成交量` | 成交量，单位为万股 | 柱状图 |
| `涨跌幅`、`每日涨跌幅`、`每日涨幅`、`每日跌幅` | 每日涨跌幅，单位为 % | 柱状图 |

图表类型可指定 `折线图` 或 `柱状图`。同一条指令只能指定其中一种；指定后会应用到该指令中的普通指标图表。双公司相对股价对比只能使用折线图。

双公司股价对比中，单独的 `涨跌幅` 表示区间涨跌幅分析；写 `每日涨跌幅`、`每日涨幅` 或 `每日跌幅` 则请求每日涨跌幅图。

## 分析与比较关键词

| 需求 | 支持的表达 | 说明 |
| --- | --- | --- |
| 收盘价最高、最低 | `最高价`、`最低价`；或在包含 `股价`/`收盘价` 时使用 `最高`、`最低` | 可以同时请求最高价和最低价；这里指模拟收盘价。 |
| 最大单日涨幅 | `涨幅最大的交易日`、`涨幅最大交易日`、`最大涨幅`、`最大涨幅的交易日` | 找出一个上涨日；没有上涨日时提示无符合条件的数据。 |
| 最大单日跌幅 | `跌幅最大的交易日`、`跌幅最大交易日`、`最大跌幅`、`最大跌幅的交易日` | 找出一个下跌日。 |
| 多个跌幅排名 | `跌幅最大的N个交易日`、`跌幅最大N交易日` | N 为正整数；仅实际下跌日参与，数量不足时会提示。 |
| 成交量排名 | `成交量最高的N个交易日`、`成交量最高N交易日` | N 为正整数，必须明确数量。 |
| 双公司比较 | `对比`、`比较` | 必须同时写 A、B 公司并指定股价或收盘价；相对走势以各自区间首日为 100。 |

其中 N 也可以搭配可选的“的”和“个”，例如 `跌幅最大3个交易日`、`成交量最高的3交易日`。同一类排名只指定一次数量。

## 可用于组织句子的词

解析器还会识别或忽略以下连接、描述词，它们本身不能代替公司、时间和指标：

`分析`、`查看`、`展示`、`用`、`并且`、`并`、`标出`、`标记`、`找出`、`列出`、`比较`、`对比`、`这段时间内`、`区间内`、`两家公司`、`走势`、`的`、`和`、`与`、`以及`、`在`、`为`、`及`。

常见空格及中文、英文逗号、句号、问号、感叹号、冒号、分号、括号、顿号可以使用。

## 推荐输入

以下可直接复制到本地模式中；预期结果根据当前代码规则整理。

| 输入 | 预期结果 |
| --- | --- |
| `查看 A 公司最近 2 个交易日的收盘价。` | 股价折线图；测试时间下限。 |
| `分析 B 公司最近 60 个交易日的股价。` | 股价折线图；测试时间上限。 |
| `用柱状图展示 A 公司最近 12 个交易日的股价。` | 股价柱状图。 |
| `用折线图展示 B 公司最近 25 个交易日的成交量。` | 成交量折线图。 |
| `分析 B 公司最近 18 个交易日的股价、成交量和每日涨跌幅。` | 股价、成交量和每日涨跌幅三张图。 |
| `查看 A 公司最近 15 个交易日的股价，并标出最低价。` | 股价图及最低收盘价标记。 |
| `查看 B 公司最近 10 个交易日的股价，并标出最高价和最低价。` | 股价图及两个极值标记。 |
| `展示 A 公司最近 20 个交易日的每日涨跌幅，并找出最大涨幅的交易日。` | 涨跌幅柱状图及最大单日涨幅。 |
| `展示 B 公司最近 20 个交易日的每日涨跌幅，并列出跌幅最大的 2 个交易日。` | 涨跌幅图和跌幅排名；符合条件不足时显示提示。 |
| `展示 A 公司最近 12 个交易日的成交量，并列出成交量最高的 5 个交易日。` | 成交量柱状图及排名。 |
| `比较 A 公司和 B 公司最近 15 个交易日的收盘价。` | 一张包含两家公司曲线的相对股价折线图。 |
| `对比 A 公司和 B 公司最近 30 个交易日的股价走势，并展示两家公司的涨跌幅。` | 相对股价折线图及各自区间涨跌幅。 |

## 连续追问

先发送 `分析 A 公司最近 30 个交易日的股价和成交量，并标出跌幅最大的 3 个交易日。`，成功生成看板后，可单独发送以下追问。每次修改基于最近一次**成功**生成的本地看板，错误不会覆盖它。

| 修改 | 支持的追问示例 | 行为与限制 |
| --- | --- | --- |
| 时间范围 | `改为最近 10 个交易日`、`改成最近20交易日` | 数量为 2～60 的整数；保留股票、图表和分析配置。 |
| 切换指标 | `成交量改为涨跌幅`、`把股价改成成交量`、`把涨跌幅改为股价` | `股价`/`收盘价`、`成交量`、`涨跌幅`/`每日涨跌幅` 可两两互换。源指标须存在，沿用源图表类型；目标指标已存在时保留已有图并移除源图。原指标不再适用的分析配置会移除。 |
| 切换图表类型 | `把股价图改成柱状图`、`成交量改为折线图`、`把柱状图改成折线图` | 指定指标时修改该指标；指定原图表类型时修改该类型的所有图。只有一张图时可用 `改成柱状图`。双公司相对股价对比仅支持折线图。 |
| 增加极值 | `增加最高价`、`添加最低价`、`标出最高价和最低价` | 指收盘价最高、最低点；当前没有收盘价图时会增加一张。已有极值会保留。 |
| 新增跌幅排名 | `标出跌幅最大的 5 个交易日`、`列出跌幅最大2交易日` | 数量须为正整数；不足时如实显示已有的下跌日。 |
| 修改跌幅排名 | `把跌幅排名改为前 5 名`、`跌幅排名改成前2名` | 当前看板须已有跌幅排名；数量须为正整数。 |
| 替换公司 | `把 A 公司换成 B`、`请把a换成b吧`、`A股票替换为B公司`、`切换到B` | 仅支持 A、B，不区分大小写；追问中可省略“公司”或“股票”。仅有一家公司时可省略被替换的公司；多公司看板须明确源公司，不能重复添加已有公司。 |
| 增加公司对比 | `增加 B 公司进行对比`、`添加B对比` | 当前看板没有该公司时可添加。股价图会变为以各自首日为 100 的相对走势；没有股价图时会新增相对走势图，并展示区间涨跌幅。 |

以上支持在关键词间加空格，句尾可加标点或“吧”“呢”“谢谢”，开头可加“请”或“麻烦”。指标、图表和公司替换支持 `改成`、`改为`、`换成`、`换为`、`替换成`、`替换为`，`把`或`将`可省略。时间追问也可写 `换成近10个交易日`。这些是有限的宽松规则，并非任意自然语言或错别字识别；复合修改请分次发送。输入无法识别、指标不存在或目标不合法时，系统会提示并保留原看板。

### 连续追问测试

1. 发送 `分析 A 公司最近 30 个交易日的股价和成交量，并标出跌幅最大的 3 个交易日。`
2. 发送 `成交量改为涨跌幅`，应保留 A 公司、30 个交易日和股价图，并显示每日涨跌幅图及跌幅排名。
3. 发送 `把涨跌幅图改成折线图`，每日涨跌幅图应变成折线图。
4. 发送 `增加最高价和最低价`，应新增收盘价极值结果。
5. 发送 `跌幅排名改为前5名`，应最多显示 5 个下跌日；符合条件不足时显示实际数量。
6. 发送 `增加B公司进行对比`，应展示两家公司相对股价走势和区间涨跌幅。
7. 发送 `改为最近61个交易日`，应提示范围无效；接着发送 `改为最近10个交易日`，应以第 6 步的有效看板为基础更新。

## 错误和边界测试

| 输入 | 预期 |
| --- | --- |
| `分析 A 公司股价。` | 提示补充时间范围。 |
| `分析 A 公司最近 1 个交易日的股价。` | 提示时间范围应为 2～60。 |
| `查看 C 公司最近 10 个交易日的股价。` | 提示仅支持 A、B 公司。 |
| `用饼图展示 A 公司最近 10 个交易日的成交量。` | 提示无法理解或不支持饼图。 |
| `对比 A 公司最近 10 个交易日的股价。` | 提示对比需要同时指定 A、B 公司。 |
| `用柱状图对比 A 公司和 B 公司最近 10 个交易日的股价。` | 提示相对股价对比只支持折线图。 |
| `分析 A 公司最近 30 个交易日的股价并预测未来走势。` | 提示不支持或无法理解预测要求。 |

当前不支持真实股票名称或代码、K 线、饼图、市盈率、营收、利润、行情预测和任意自由问答。
