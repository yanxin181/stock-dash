# 问数：股票分析对话 MVP

本项目实现阶段一的最小对话切片：本地规则识别、固定模拟数据计算、对话气泡和回复，支持选择本地模式或大模型模式。大模型模式目前只展示未接入提示。此版本尚未实现文档中的 Schema 校验、图表看板、过程状态及完整异常覆盖，不应视为阶段一全部交付。

## 运行

需要 Node.js。首次运行 `npm install`，随后运行 `npm run dev` 并打开终端给出的本地地址。运行 `npm test` 执行测试，`npm run build` 构建。依赖安装完成后，本地分析不需要网络或 API Key。

## 数据与能力

数据由固定公式生成，截止 2026-01-30，覆盖 61 个工作日（按周一至周五生成，未排除节假日）；价格为模拟收盘价（元），成交量单位为万股。支持 A、B 公司及 2–60 个交易日。每日涨跌幅 =（当日收盘价 − 前一交易日收盘价）/ 前一交易日收盘价；区间涨跌幅以区间首日为基准。上一条有效需求可用于“改为最近 10 个交易日”或“把成交量改成涨跌幅”等简单追问，无法识别的追问不会覆盖它。界面内示例可点击填入并发送。

规则识别仅覆盖有限表达方式，不连接真实行情，不支持预测；结果仅用于演示。问财 Skill 尚未调研或接入。
